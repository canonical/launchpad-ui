to you too. This file adds AI-specific working guidance, not a second set of
coding conventions.

CODING_STANDARDS tell to limit the amount of tests, but if you need them to speed up the checks during the implementation then go ahead and write all the tests you need. Delete ones that do not fit the standards afterwards.
